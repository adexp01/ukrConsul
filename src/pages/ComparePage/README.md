# Порівняння «до / після» — /internal/compare

Службова сторінка: два кадри з одного домену поруч або під шторкою.
Ліворуч — знімок сайту на комміті `ec9408c` (12.07.2026, останній перед
серією правок), праворуч — поточний `main`.

Сторінки немає ні в меню, ні в `sitemap.xml`; `robots.txt` закриває
`/internal/` і `/legacy/`, сама сторінка ставить `noindex, nofollow`.
Код їде окремим чанком через `lazy` — у бандлі публічного сайту його немає.

## Звідки береться ліва половина

`public/legacy/` — це готовий білд старої версії, покладений у репозиторій
як статика. Він не збирається разом із сайтом і ні на що не впливає, крім
ваги. `vercel.json` має правило `/legacy/(.*)` → `/legacy/index.html`, щоб
клієнтські маршрути старого SPA (`/legacy/ua/about-us`) не провалювались у
фолбек основного застосунку. Реальні файли Vercel віддає до правил, тому
`/legacy/assets/*` це правило не чіпає.

## Як перезібрати знімок на інший коміт

```bash
git worktree add ../legacy-src <commit> --detach
cd ../legacy-src
```

Далі в цій копії:

1. `vite.config.js` → додати `base: "/legacy/"` і `build.assetsInlineLimit: 0`.
2. `src/App.jsx` → `<BrowserRouter basename="/legacy">`.
3. Прибрати з `public/` усе, що не потрібне знімку (на `ec9408c` це
   `animation/frames2`, `animation/frames3` — 82 МБ мертвих ассетів — і
   всі формати шрифтів, крім `.woff2`).
4. Кадри щита перевести в `webp` і лишити тільки ті, що реально грають
   (кожен другий із 0…178), а в `SpriteCanvas.jsx` замінити розширення.
5. `npm ci && npm run build`.
6. Стиснути зображення в `dist/assets`: до 1600 px по довшій стороні,
   PNG — палітра на 200 кольорів, JPEG — якість 72. Без цього білд важить
   97 МБ проти 16 МБ після.
7. `rm -rf dist/animation` — публічну копію кадрів дублює бандл.
8. `cp -r dist/. ../ukrConsul/public/legacy/`.

Верстка, стилі й поведінка при цьому лишаються оригінальними: змінюється
лише вага картинок і формат кадрів.

## Що всередині сторінки

- Режими: пліч-о-пліч, шторка, тільки стара, тільки нова.
- Пристрої: 1440×900, 1280×800, 834×1112, 390×844. Кадр вписується цілком,
  щоб перший екран порівнювався за тією висотою вікна, яку заявлено.
- Спільний скрол: обидва документи з одного домену, тому позиція
  переноситься напряму через `contentWindow`, у частках від висоти
  сторінки — версії різної довжини.
- «Цифри» — п'ять фактів, знятих із репозиторію.
